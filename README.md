# explainer-videos

Sources for the "HOW? / КАК?" explainer series (RU + EN). See `CLAUDE.md` for the full workflow.

- `tools/` — voiceover (ElevenLabs), timing fit, captions, rendering and audio mix scripts
- `videos/<topic>/` — each video's scripts, voice/music assets and animation code
- `brand/` — avatars, YouTube banner, Instagram covers
- `instagram_posts.md` — titles, captions, hashtags, pinned comments

Rendered MP4 files are not stored in git.
